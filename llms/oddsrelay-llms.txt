# OddsRelay

> The odds feed, raw or ready-matched. OddsRelay is a B2B odds-data supplier: 140+ bookmakers · 60+ live in the UK & Ireland, delivered as one keyed REST API at https://api.oddsrelay.io (version 2026-07-08).

OddsRelay supplies odds data only and takes no bets. Customers license access to the data, never the methods behind it.

## About OddsRelay

OddsRelay is an odds-data API for businesses. It serves odds from 140+ bookmakers, 60+ of them live in the UK & Ireland, through one keyed REST API, as two co-equal products: each bookmaker's raw prices, and matched feeds where every bookmaker back price is already paired with the best lay price on Betfair, Smarkets, Matchbook and BETDAQ and the money available at that lay (six feed types). bet365 is included in every plan. Every product on sale meets a maximum update time of 10–20 s: how old a bookmaker's price can be when it reaches you. OddsRelay is a data supplier, not an operator, and takes no bets.
